## Locked product decisions

- Same-room TV play; phones provide private information and controls. Host proxy supports manual participants where privacy permits. No remote-play/voice-chat scope.
- One entitled team attempts first. One assigned captain submits; teammates discuss aloud. Explicit Arabic confirmation commits an answer; draft selections remain editable until commit/expiry.
- Tile/map failures offer a 15-second opponent steal. Host starts or declines; selected wrong answer and solution remain hidden until both opportunities close. Navigation/memory have no steal.
- Automatic server grading, with the existing audited host correction mechanism. Failure leaves the cell unclaimed; revisiting draws fresh eligible content. Terminal result persists until host continues.
- Host-controlled audience solution reveal only after all attempts close. Generic legacy reveal/failure must not bypass this rule.
- Room-wide labelled-colour accessibility is selected before the match and fixed during it. Colour names accompany content colours; no separate shape-memory content scope.
