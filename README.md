# Almaidan

Almaidan is the active application in this project root.

- `npm run dev` or `npm start` starts the guarded local stack without admin identity provisioning.
- `npm run build:local` builds the isolated local web artifact.
- See [LOCAL-ALMAIDAN.md](LOCAL-ALMAIDAN.md) for local services and startup details.

The previous Alkhaliya application is preserved in [old_app](old_app/). Shared local state and data remain in `local/`, `content/`, `data/`, and `output/` at the project root.
